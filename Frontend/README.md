# HomelyHub Frontend

React 18 + Vite frontend for HomelyHub (Web Stack Academy MERN Stack Internship project).
See the main [README](../README.md) for full details.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

Environment: `VITE_API_BASE_URL` (default `/api`, proxied to `http://localhost:8080` by Vite in dev).
